# Security

Please report vulnerabilities privately to **support@metricmind.si** with "Security" in the subject, not in a
public issue. Include the affected package and version, how to reproduce it, and its impact.

We'll acknowledge your report, keep you updated while we fix it, and credit you when the fix ships if you wish.

This covers the code in this repository (the browser script, mobile SDKs and server helpers). Issues in the
hosted MetricMind service can be reported to the same address.
